# Final Exam deliverables

Updated documentation for the final-exam version of the Blood Bank Donor & Inventory Management System
(API data, machine-learning models deployed in Django, predictive dashboard). The midterm versions are
kept unchanged in the parent `docs/` folder.

| File | Contents |
|---|---|
| `Project_Report.pdf` | Final exam project report (25 pages, same format as the midterm report) |
| `er_diagram.png` | Updated ER diagram: 14 entities across 4 apps, including the new analytics app |
| `er_diagram.html` | Source of the ER diagram, with the full relationships and cardinality table |
| `screenshots/` | 27 screenshots of the current system |
